## About This Repository

This repository contains my personal notes, summaries, and architectural diagrams for the book **[Designing Data-Intensive Applications](https://dataintensive.net/)** by Martin Kleppmann & Chris Riccomini. 

The goal of these notes is to distill the core concepts, trade-offs, and architectural patterns required to build reliable, scalable, and maintainable data systems. It serves as a quick reference guide and a structured way to review the material, covering everything from operational vs. analytical systems to the complexities of distributed transactions and consensus.
